## 2. このタスクのゴール

データの書き出し・読み込みを行う「データのバックアップ画面」を新規実装し、登録情報
ハブ画面（`MasterPage.tsx`）に「データ管理」セクションと導線を追加し、ルーティングを
接続する。画面本体・導線・ルーティングを1タスクにまとめる（`50_タスク作成ルール.md`
「ルーティング・E2E検証に関する方針」。遷移先画面が無い状態で導線だけを先に生やさない）。

公開版・自チーム版の両方に表示する画面であり、`import.meta.env.MODE === 'public'`で
案内文・警告文を出し分ける（04_画面設計.md#10.5「自チーム版での文言の違い」）。

## 4. 実装範囲（やること）

### `BackupPage.tsx`

- `Header`コンポーネントで戻るボタン付きヘッダー「データのバックアップ」を表示する
  （`MasterPage.tsx`の`Header title="登録情報" backTo="/"`と同様の使い方。
  `backTo`は`/master`）
- 案内文（`04_画面設計.md#10.5`のバナー文言。`import.meta.env.MODE === 'public'`で
  公開版／自チーム版の文言を出し分ける）
- 「バックアップを書き出す」カード
  - ボタン押下で`backupService.exportAllData()`を呼び、結果をJSON文字列化して
    `Blob`＋`URL.createObjectURL`＋`<a download>`の標準的な方法でファイルダウンロードする
    （ファイル名案：`carpoolbridge_backup_YYYYMMDD_HHmm.json`。指定通りにならない
    ブラウザがある点は許容する。docs/12_データバックアップ機能設計.md#4）
  - 成功後、「最終書き出し: YYYY-MM-DD HH:mm」をこの画面のローカル状態として表示し、
    完了トースト「バックアップを書き出しました」を表示する（ページ再訪時は消えてよい。
    永続化しない）
- 「バックアップを読み込む」カード
  - `<input type="file" accept="application/json">`でファイルを選択させる
  - 選択後、`file.text()`→`JSON.parse`を試みる。失敗、または`schemaVersion !== 1`の
    場合はエラートースト「このファイルは読み込めません（形式が正しくありません）」を
    表示して中断する（確認ダイアログは出さない）
  - パースに成功した場合、`BackupImportConfirmDialog`を表示する
  - 警告文（`04_画面設計.md#10.5`。`import.meta.env.MODE === 'public'`で出し分け）
- `BackupImportConfirmDialog`で「読み込む」が選択されたら`backupService.importAllData(data)`
  を実行し、成功したら`navigate('/')`でホーム画面へ遷移したうえで、ホーム画面側に
  完了トースト「データを読み込みました」を表示させる（トーストの実装は簡易な状態受け渡し
  で良い。例：`navigate('/', { state: { toast: 'データを読み込みました' } })`とし、
  `HomePage`側で`location.state`を読んで表示する。`HomePage`側の対応も本タスクに含める）

### `BackupImportConfirmDialog.tsx`

- `CarpoolRecreateDialog.tsx`と同じ構成（`role="dialog"`のオーバーレイ、`Button`使用）
- タイトル・メッセージ・ボタンは`04_画面設計.md#10.5`「読み込み確認ダイアログ」の通り
  （`import.meta.env.MODE === 'public'`でメッセージの一部を出し分け）

### `MasterPage.tsx`

- `menuItems`の`Card`一覧の下、`<hr>`（開発用機能との区切り）の上に、「データ管理」の
  見出しラベルと、`💾`アイコンの行（「データのバックアップ」・遷移先`/master/backup`）を
  追加する（`04_画面設計.md#10.1`のモックの通り）

### `router/index.tsx`

- `<Route path="/master/backup" element={<BackupPage />} />`を追加する

## 6. 受け入れ条件

- 登録情報ハブ画面に「データ管理」見出しと「データのバックアップ」行が表示され、
  タップで`/master/backup`へ遷移する
- 「バックアップを書き出す」でJSONファイルがダウンロードされる
- 正しい形式のファイルを読み込むと確認ダイアログが表示され、「読み込む」で
  全置換が実行された後、ホーム画面へ遷移し完了トーストが表示される
- 形式が不正なファイルを読み込むと、確認ダイアログを経由せずエラートーストが表示される
- `import.meta.env.MODE === 'public'`かどうかで、案内文・警告文・確認ダイアログの文言が
  `04_画面設計.md#10.5`の表の通り切り替わる
- `npm run build`が成功する
