# 対象設計書

ref: docs/13_TWA・Google Play公開設計.md#6

# ゴール

Google Playストア掲載の必須項目であるプライバシーポリシーを、公開版アプリ内の
静的ページ（`/privacy`）として追加する。

# 変更対象ファイル

- `src/pages/PrivacyPolicyPage.tsx`（新規）
- `src/router/index.tsx`

# 実装範囲（やること）

- `PrivacyPolicyPage`コンポーネントを新規作成する
  - 他ページと同様`Header`（`backTo="/"`）を使用する
  - 掲載内容はdocs/13#6.2に従う（取得する情報はない旨、Cookie等不使用、
    第三者提供なし、お問い合わせ先はGitHubリポジトリのIssueページ）
  - データ取得・認証は行わない（純粋な静的表示）
- `src/router/index.tsx`に`/privacy`ルートを追加する（他画面と同様`React.lazy`で
  コード分割する）

# 実装範囲外（やらないこと・触らないこと）

- ホーム画面・登録情報画面等、既存画面からこのページへの導線（リンクボタン等）の
  追加は行わない。URLから直接到達できれば足りる（`docs/50`「新規画面を実装する
  タスクでは最小限のルーティングを実装範囲に含める」を満たす）。導線が必要になった
  場合は別タスクとする
- `@app-shell`エイリアスによる自チーム版・公開版の出し分けは行わない
  （docs/13#4.3参照。両ビルドに同じルートが含まれる）
- `.well-known/assetlinks.json`関連（T96で対応）

# 受け入れ条件（完了判定基準）

- `npm run dev`（または`build`後の`preview`）で`/privacy`にアクセスし、
  プライバシーポリシーの内容が表示できる
- `npm run build`・`npm run build:public`・`npx eslint .`が通る

# 依存タスク

- なし
