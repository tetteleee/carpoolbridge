## 2. このタスクのゴール

公開版（Dexie）向けのE2Eテストを実行するための基盤（ビルドmode・デバッグ用windowフック・
Playwright設定・fixtures）を新設する。このタスク単体ではテストケース本体は作成しない
（T90で実施）。

## 3. 変更対象ファイル（想定）

- `vite.config.ts`（`mode === 'public'`判定を`mode.startsWith('public')`に変更）
- `src/repositories/dexie/db.ts`（デバッグ用windowフック追加）
- `.env.public-e2e`（新規）
- `playwright.public.config.ts`（新規）
- `e2e-public/utils/fixtures.ts`（新規）
- `e2e-public/utils/seedDexie.ts`（新規）
- `package.json`（`test:e2e:public`スクリプト追加）

---

## 4. 実装範囲（やること）

- `vite.config.ts`の`@repository`・`@app-shell`エイリアス判定を`mode === 'public'`から
  `mode.startsWith('public')`に変更する（`public`・`public-e2e`どちらでもDexie版・
  `PublicAppShell`が使われるようにするため）
- `src/repositories/dexie/db.ts`の末尾に、`import.meta.env.VITE_EXPOSE_DEXIE_DB === 'true'`の
  場合のみ`db`インスタンスを`window.__dexieDb`として公開する処理を追加する
  （docs/10_DexieRepository実装設計.md#8のコード例参照）
- `.env.public-e2e`を新設し、`VITE_EXPOSE_DEXIE_DB=true`を設定する
- `playwright.public.config.ts`を新設する。既存`playwright.config.ts`をベースに、
  以下を変更する。
  - `testDir: './e2e-public'`
  - `webServer`はVite開発サーバーのみ（Firebase Emulatorの起動は不要）。
    `command: 'npm run dev -- --mode public-e2e --host 127.0.0.1 --port 5174'`のように
    既存の自チーム版E2E（ポート5173）と衝突しないポートを使う
  - `use.baseURL`もポート5174に合わせる
- `e2e-public/utils/fixtures.ts`を新設する。既存`e2e/utils/fixtures.ts`から
  `clearFirestore`関連を除いた形（`skipTutorial`のauto fixtureのみ）にする
  （Playwrightは既定で各テストに新しいBrowserContextを割り当てるため、IndexedDBの
  明示的クリアは不要。docs/10#8参照）
- `e2e-public/utils/seedDexie.ts`を新設する。`page.evaluate()`で
  `window.__dexieDb`のテーブルへ直接書き込むヘルパー関数群を用意する
  （例: `seedPickupLocation`・`seedFamily`等、T90で実際に必要になる分だけ用意する）
- `package.json`の`scripts`に`"test:e2e:public": "playwright test --config=playwright.public.config.ts"`を追加する

## 6. 受け入れ条件

- `npm run build`・`npm run build:public`が引き続き成功する
  （`mode.startsWith('public')`への変更で自チーム版の判定に影響がないことを確認する）
- `npm run dev -- --mode public-e2e`でアプリが起動し、`window.__dexieDb`が
  ブラウザのコンソールから参照できる
- `npm run build:public`（本番の公開版ビルド、`VITE_EXPOSE_DEXIE_DB`未設定）の成果物に
  `__dexieDb`・`VITE_EXPOSE_DEXIE_DB`関連のコードが含まれない
- `npm run lint`が成功する
